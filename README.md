## 1. Overview

The manuscript introduces a system-centered probabilistic formalism for characterizing the ecological and evolutionary dynamical systems.

For each sampled parameterized system, the code enumerates possible supports, computes candidate equilibrium states, classifies them according to a prescribed equilibrium type, and summarizes the results at the system level.

The framework is applied to two model families:

1. generalized Lotka-Volterra systems
2. replicator dynamics

For generalized Lotka-Volterra systems, the code classifies states as saturated or stable.
For replicator dynamics, the code classifies states as saturated, stable or evolutionarily stable states.

The outputs included in this repository are the simulation results used to generate the figures in the manuscript.

## 3. Description of the files

### `classification_utils_GLV.py`

This file contains the functions used for generalized Lotka-Volterra systems.

It includes functions for:

* generating random and structured GLV interaction matrices
* enumerating supports
* computing candidate equilibria
* testing whether states are admissible, saturated or locally stable
* classifying all states generated by a given GLV system

The GLV model considered in the manuscript has the form:

dx_i/dt = x_i (r_i + (Ax)_i),

where `A` is the interaction matrix and `r` is the growth rate.

### `classification_utils_replicator.py`

This file contains the functions used for replicator dynamics.

It includes functions for:

* generating random and structured fitness matrices
* constructing interaction matrices depending on the parameter `mu`
* enumerating non-empty supports
* computing candidate equilibria in the simplex
* testing saturation, asymptotic stability and evolutionary stability
* classifying all states generated by a given replicator system

### `formalism.py`

This file contains the system-centered probabilistic formalism.

The main functions compute, for each sampled system and each equilibrium type:

* the vector `F_p`, which describes absence and state-size distribution within a system;
* the number of states `S_p`;
* the number of states of each size `S_p^k`;
* Monte Carlo averages over independently sampled systems.

In particular:

* `analyze_one_system` computes the system-level summaries for one parameterized system;
* `monte_carlo_full` repeats the computation over many sampled systems.

### `figures.ipynb`

This notebook loads the processed simulation outputs stored in the `data/` folder and reproduces the figures used in the manuscript.

## 4. Data files

The files in the `data/` folder are processed simulation outputs stored as Python pickle files.

The suffix `e4` indicates that the simulations were run with:

M = 10000

Monte Carlo sampled systems.

The main data files are:

* `glv_random_pos_e4.pkl`: GLV simulations for the random competitive structure
* `glv_grid_all_e4.pkl`: GLV simulations over the two-dimensional grid of connectance and interaction strength
* `glv_c*_sigma_0_3_e4.pkl`: GLV simulations along the interaction strength parameter for fixed connectance values
* `replicator_random_e4.pkl`: replicator simulations for the random structure
* `replicator_mu_e4.pkl`: replicator simulations along `mu`
* `replicator_all_e4.pkl`: additional replicator outputs used for the manuscript figures.

These files contain processed Monte Carlo summaries.

## 6. Reproducing the figures

To reproduce the figures, open the notebook:

```bash
jupyter notebook figures.ipynb
```

Then run all cells.

The notebook loads the processed simulation outputs from the `data/` folder. The expected loading structure is:

```python
from pathlib import Path
import pickle

ROOT = Path.cwd()
DATA_DIR = ROOT / "data"

def load_results(filename):
    path = DATA_DIR / filename
    with open(path, "rb") as f:
        return pickle.load(f)
```

The notebook should therefore be launched from the folder containing both `figures.ipynb` and the `data/` folder.

## 7. Re-running simulations from scratch

The outputs are included because the full simulations may take long computational time.

The simulations involve:

* exhaustive enumeration of all supports
* Monte Carlo sampling over many independently generated systems
* classification of candidate states for each sampled system

The main settings used in the manuscript are:

N = 10
M = 10000

where `N` is the number of species, and `M` is the number of independently sampled systems.

For GLV systems, all supports are considered, including extinction.
For replicator dynamics, all non-empty supports are considered.
